# Contributing to Echo: Gesture-Controlled Virtual Mouse and Voice Assistant

Thank you for your interest in contributing to Echo!  
This project is open-source, and we’d love to have you collaborate with us. Whether you're a beginner or an expert, your contributions are welcome.

## How to Contribute

### Fork the Repository
- Click the **Fork** button at the top right of this page.
- Clone your forked repository:
  ```bash
  git clone https://github.com/your-username/Gesture-Controlled-Virtual-Mouse-and-Voice-Assistant.git
- Navigate to the project directory:
  ```bash
  cd Gesture-Controlled-Virtual-Mouse-and-Voice-Assistant
- Create a new branch for your feature or fix:
  ```bash
  git checkout -b feature-name
- Make Your Changes
- Commit your changes with a meaningful message:
  ```bash
  git add .
  git commit -m "Add feature/fix: Description"
  git push origin feature-name
- Submit a Pull Request

## What Can You Contribute?
- New gestures or voice commands
- Bug fixes
- Code optimization
- UI/UX improvements
- Documentation and README improvements
- Test cases and error handling
- New features

## Code Guidelines
- Use clear and consistent naming conventions.
- Write clean, readable code.
- Document your functions and modules.
- Test before submitting!
